# Budget Tracker - Visual Identity (CSS)## Project DescriptionThe Budget Tracker is a personal finance application designed to help users record and review their expenses.This week's assignment focuses on improving the visual identity and user interface of the existing Budget Tracker using CSS.## Color PaletteThe project uses a consistent, professional color palette:- **Navy Blue (#16324f):** Main headings and table headers.- **Teal (#0d9488):** Buttons and interactive elements.- **White (#ffffff):** Content cards and table backgrounds.- **Light Gray (#f1f5f9):** Main page background.- **Dark Gray (#243447):** Body text.These colors create a clean and readable interface.## TypographyThe project uses two Google Fonts:- **Poppins:** Used for main and section headings.- **DM Sans:** Used for body text, labels, form controls, buttons, and table content.The font pairing improves readability and creates a clear visual hierarchy.## Files and Their Purpose### 1. index.htmlThe HTML file provides the existing Budget Tracker page structure, including the page heading, Add Expense form, and Expense Table.### 2. style.cssThe CSS file controls the visual appearance of the application. It includes:- A consistent color palette.- Google Fonts typography.- Styled form inputs and buttons.- Table borders, spacing, and alternating row colors.- Card-style sections with padding, margins, shadows, and rounded corners.- Responsive styling for smaller screens.- Focus and hover effects for improved usability.### 3. README.mdThis file explains the purpose of the project, the design choices, and the role of each project file.## CSS Box ModelThe CSS Box Model is applied throughout the project:- **Margin:** Separates the page heading, form card, table card, and footer.- **Padding:** Creates comfortable space inside cards, inputs, buttons, and table cells.- **Border:** Defines the edges of cards, form controls, and the table.- **Border-radius:** Gives cards, inputs, and buttons rounded corners.- **Box-sizing:** Makes element dimensions easier to manage consistently.## Table and Form StylingThe Add Expense form uses consistent input sizes, clear labels, rounded borders, and a teal submit button.The Expense Table uses a navy header, padded cells, subtle borders, alternating row colors, and a hover effect to make information easier to read.## Responsive DesignA CSS media query adjusts the layout for smaller screens. The form changes to a single column on narrow screens, and the table can scroll horizontally when needed.## Learning OutcomesThrough this assignment, I practised:1. Applying a consistent CSS color palette.2. Using Google Fonts to improve typography.3. Styling HTML forms and tables.4. Applying margin, padding, borders, and border-radius.5. Organizing page sections into visual cards.6. Making the layout responsive.## ConclusionThis assignment improves the visual identity of the existing Budget Tracker by making its interface more consistent, readable, organized, and user-friendly.The focus is on CSS design while preserving the existing application's functionality.
